# Documentation Style

Guidelines for writing clear, professional documentation that reduces generic AI-sounding prose.

## Source

SRC-0019: Google Developer Documentation Style Guide principles applied to AI-generated content.

## Core Principles

The Google Developer Documentation Style Guide emphasizes:

1. **Clarity over formality** — Use simple, direct language. Avoid jargon unless necessary.
2. **Consistency** — Use the same terms and conventions throughout.
3. **Completeness** — Provide necessary context and examples.
4. **Accuracy** — Verify all claims and examples work.
5. **Accessibility** — Write for your audience's knowledge level.

## Rules for Less Generic AI Prose

### Avoid
- "In today's digital landscape..." (cliché opening)
- "It is important to note that..." (filler)
- "As we all know..." (assumes universal knowledge)
- "Cutting-edge technology" (vague praise)
- "Seamlessly integrate" (marketing speak)
- Excessive qualifiers ("very", "quite", "really")

### Prefer
- Specific language over general
- Active voice over passive
- Direct instructions over explanations
- Examples over abstract descriptions
- Verifiable claims over opinions

## Example Transformations

**Generic AI:** "Leveraging best-in-class design principles enables you to craft visually stunning interfaces that seamlessly delight users."

**Documentation style:** "Apply consistent spacing, typography, and color to create professional interfaces."

**Generic AI:** "It is important to consider that accessibility plays a vital role in inclusive design."

**Documentation style:** "Accessible design ensures your interface works for users with disabilities."

## When to Use This Skill

- Writing documentation, guides, or tutorials
- Creating prompts for AI that will produce written content
- Refining AI-generated prose that sounds too generic
- Establishing consistency in voice across multiple documents

## Implementation

1. Define your documentation's audience and context
2. Apply the principles above to your writing or prompts
3. Prefer specificity and directness over flourish
4. Test: does this sound like a real person or generic AI?
