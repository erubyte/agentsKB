# Design Skills Directory

Curated reference of frontend design skills and tools for AI-assisted visual work.

## About This Skill

When building visual interfaces (websites, dashboards, apps), this skill provides a reference list of available design skills and approaches to evaluate.

Source: SRC-0008, community-collected design tools.

## Design Skills Categories

### Visual Design & Aesthetics
- Frontend Design — Core UI/UX principles and implementation
- Apple Design — iOS/macOS design patterns and guidelines
- Beautiful Shadows — Shadow and depth techniques
- Emil's Design Engineering — Design systems and component architecture

### Accessibility & Usability
- Accessibility — WCAG, screen readers, keyboard navigation, color contrast
- Design Review — Evaluating designs against best practices
- Better Interface — UX improvements and interaction patterns

### Implementation & Frameworks
- Shadcn — React component library and patterns
- Adapt — Responsive design and adaptive layouts
- Interaction Design — Animations, transitions, user feedback

## How to Use This Skill

When starting a visual project:

1. Review the categories above
2. Identify which skills apply to your project (design systems, accessibility, responsiveness, interactions)
3. Use relevant skills to inform the design brief
4. Validate that tools exist and are current before committing to them in your prompt

## Important Notes

- This directory is a reference, not a guarantee of current availability
- Tools and skills change; verify they still exist before using them
- No single skill solves all design problems; combine multiple approaches
- This list should be curated based on what tools actually work with Claude

## Next Steps

- Evaluate each skill against your specific project needs
- Test skills on small tasks before using on production work
- Update this list as new design skills become available or existing ones change

## Evidence Status

Untested. This is a reference directory, not a validated practice. Use as a starting point for design skill selection, not as definitive guidance.
